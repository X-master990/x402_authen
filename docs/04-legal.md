# 法律自保清單（具體化版）

> 核心原則只有一句：**我們發表的每一個字，都要能在法庭上指著存證檔案說「這是量測結果，不是我的意見」。**
> 三原則：只呈現可驗證數據｜方法論全公開可下載｜初期用代號不點名。以下把三原則落成可以照抄的範本。

---

## 一、方法論頁面範本（榜單網站必備頁，上線第一天就要有）

榜單 A、B 各一頁，結構相同。以下為榜單 A 版本，`{}` 處填實際值：

```markdown
# 量測方法論（Methodology）v{版本號}，最後更新 {日期}

## 我們量什麼
對 x402 Bazaar 上自我歸類／描述為金融行情數據的服務，我們定期用 x402
協議實際付費呼叫，記錄四個指標：
1. 存活率：付費請求是否得到 HTTP 200 與可解析回應。
2. 延遲：從送出請求到收到完整回應的毫秒數（由 {機房位置} 的探測節點量測）。
3. 報價誤差：回應中的價格 vs 同一時刻權威來源的偏差（basis points）。
4. 時間戳漂移：回應宣稱的數據時間 vs 我們收到回應的實際時間差。

## 權威來源（Ground Truth）
{Binance、Coinbase Exchange、OKX} 官方 API 同刻報價的**中位數**。
單一來源異常時自動剔除。權威來源本身的取得時間戳同樣存檔。

## 量測流程
- 探測頻率：{頻率說明；註明抽樣策略}。
- 每次探測完整保存：原始 HTTP 回應、回應標頭、鏈上付款交易 hash、
  我方送出/收到的時間戳（NTP 校時）。
- 每日將全部存證檔案的 SHA-256 雜湊彙整為 Merkle root，發佈於 {位置}。
  任何人可驗證我們事後未竄改任何一筆紀錄。

## 評分公式
{完整公式，含權重。與 docs/01-architecture.md 同步}

## 限制與免責
- 我們量測的是「我們的探測節點在特定時刻觀察到的行為」，不保證代表
  該服務對所有使用者、所有時刻的行為。
- 網路路徑、對方限流、鏈上壅塞都可能影響單次量測；因此榜單分數一律
  以 {N} 次以上的統計值呈現，不以單次結果評分。
- 本榜單為基於公開方法論的量測性意見，不構成投資建議或商業誹謗之
  事實陳述。

## 原始數據下載
{連結}：全部探測紀錄 CSV/JSON，含存證雜湊。

## 申訴與更正（Right of Reply）
你是榜上服務的經營者且認為量測有誤？來信 {email}。我們承諾：
- 7 天內回覆；
- 若確認我方量測錯誤，公開更正並在榜單標註更正紀錄；
- 你的回應可全文刊登於該服務的榜單頁面。
```

**要點**：「申訴與更正」段落是最強的自保——法律上展現善意、實務上是跟賣家開啟對話（銷售線索）的正當管道。

## 二、代號規則（榜單 B 尤其重要）

1. **讚美用真名，批評用代號。** 表現好的服務直接點名（他們會轉發你）；表現差的一律用代號 `#V-001`（賣家）/ `#S-001`（訊號商）。
2. 代號 ↔ 真實身分的對照表**離線保存、不放進任何公開 repo 或資料庫**。
3. **升格點名（de-anonymize）需同時滿足四條件**：
   - 異常行為連續 ≥ 4 週、有 ≥ 20 筆獨立存證；
   - 已透過可觸及的聯絡方式通知對方，給滿 7 天回應期；
   - 對方未回應，或回應無法解釋數據；
   - 完整證據包（原始回應 + 付款 hash + 時間戳）已封存並可公開下載。
4. 點名時的用語紀律：只寫量測事實（「該服務於 X 期間報價偏離權威來源中位數達 Y bps，存證見 Z」），**不寫動機推斷**（不用「詐騙」「造假」「割韭菜」等定性詞——讓讀者自己下結論）。
5. 訊號商成績單追加一條：只結算「發佈當下已蓋時間戳」的訊號，事後補收的歷史訊號一律不採計、不評論。

> All content on this site is automated measurement data and statistical opinion produced under a publicly documented methodology. It is provided for informational purposes only and does not constitute investment advice or factual accusations against any service. See our Methodology page for inherent limitations.

**電子報/長文文末（簡版）**：

## 四、台灣法規面（每季檢查一次，下次檢查：2026-11 中）

- **收款**：USDC 收入走公司帳、開發票、正常報稅。純賣服務（監測訂閱、企業導入）收穩定幣，目前一般不觸發 VASP 登記；**但虛擬資產專法立法中**，每季確認一次現況。判斷紅線：只要不碰「代客買賣/兌換/保管虛擬資產」，就停留在安全區。
- **誹謗風險**（刑法 310/311 + 釋字 509 脈絡）：自保依靠三件事——(1) 陳述有存證的事實而非臆測、(2) 榜單屬「可受公評之事」的適當評論、(3) 發表前已盡查證義務（方法論 + 申訴管道就是查證義務的書面證明）。第二節的代號規則就是把這三件事程序化。
- **個資**：榜單只處理服務/錢包地址層級的數據，不處理自然人個資；訊號商若為個人經營，點名前多過一次第二節第 3 條的四條件。
